Дата: 2026-10-26
Среда: Linux x86_64, Python 3, pytest. Windows / .NET / Wine отсутствуют.

УСПЕШНО:
- Компиляция исходного Python (compileall).
- 24 pytest теста проверяют валидацию, генерацию подключения,
  фильтрацию имён, распознавание каталогов, модель операций публикации.
- Наличие WinSCP.exe и WinSCP.com в комплекте.

НЕ ПРОВЕРЕНО:
- Выполнение программы в Windows.
- Реальный WinSCP.com с вводом команд по stdin и парольная авторизация.
- SSH-соединение с сервером колледжа.
- Интеграционные тесты с локальным SFTP.
- Alt+Tab, Windows UI/DPI 100–200%, диалог Проводника.
- Полная устойчивость при сетевом обрыве в критический момент публикации.
- Совместимость 32-бит Windows, Windows 7.
- Работа под разными учётными записями Windows (не поддерживается).

ВЫВОД: проект НЕ готов для производственной эксплуатации без тестирования
на Windows и тестовом SFTP. Не следует выдавать его за стабильный релиз.
