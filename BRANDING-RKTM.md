# РКТМ — единое приложение 5.0.0

Принятый макет: светлая верхняя навигация «Расписание / История / Настройки»,
белые панели на сером фоне, три шага публикации, крупные кнопки импорта,
таблица файлов, красное основное действие, жёлтый индикатор текущего шага.
Логотип: предоставленный RKTM-Brandbook-Assets.zip, страница 3 брендбука.
Цвета: #E51F22, #FFDB57, белый, чёрный, светло-серый. Шрифт интерфейса Segoe UI.
Таблица показывает достоверные имя, размер и состояние, без угадывания
раздела расписания по названию файла.

Реализация: стандартный Tkinter/ttk, без браузерного движка и Pillow в коде UI.
Pillow применяется только для снимков реальных окон в CI.
Один исполняемый файл запускает все три раздела. Ключ --admin открывает настройки.
Установщик x86 (Python 3.8, PyInstaller 5.13.2, Inno Setup 6.2.2)
предназначен для Windows 7 SP1 и новых 32/64-битных систем.
Проверки на современном Windows runner не доказывают запуск на Windows 7.
Настройки прежних версий сохраняются в APPDATA/RKTM-Rebuild.
Журнал содержит только дату и числа файлов, без паролей и ответов сервера.
