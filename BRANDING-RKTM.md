# РКТМ — оформление приложения 4.7.0

Логотип взят из предоставленного набора RKTM-Brandbook-Assets.zip (страница 3 брендбука).
Основные цвета: красный #E51F22, жёлтый #FFDB57, белый и чёрный.
Иконки Windows включают размеры от 16 до 256 px. Логотип сохраняет пропорции.

Установщик x86 работает на 32- и 64-битной Windows 8.1 и новее.
Установщик x64 предназначен только для 64-битной Windows 8.1 и новее.
Для Windows 7 SP1 предусмотрена отдельная сборка x86 на Python 3.8.
Установка выполняется для текущего пользователя. Инструменты администратора выбираются отдельно.
Конфигурация хранится в APPDATA/RKTM-Rebuild и не удаляется деинсталлятором.

Успешная сборка в CI не заменяет проверку на реальной Windows 7/10/11.
Для подтверждённого издателя требуется доверенный сертификат подписи кода.
