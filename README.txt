РКТМ — экспериментальная переработка v4 (исходный код + WinSCP Portable)

ВАЖНО: Это НЕ готовый протестированный Windows EXE. В текущей Linux-среде
нет Windows или Windows-сборщика Python-приложений. Не используйте для
рабочего расписания, пока не проведены тесты на тестовом SFTP-сервере.

Запуск на Windows 10/11:
1. Требуется установленный Python 3 с Tkinter (Python.org).
2. Распакуйте папку целиком (WinSCP/WinSCP.com должен быть на месте).
3. Дважды щёлкните Запустить-Администратор.bat.
4. Укажите адрес сервера, пользователя, порт, пароль и проверенный SSH-отпечаток.
5. Подключитесь, откройте папку двойным щелчком, сохраните.
6. Запустите Запустить-Расписание.bat, выберите HTML-файлы и опубликуйте.

ОГРАНИЧЕНИЯ БЕЗОПАСНОСТИ:
- Пароль защищён DPAPI для текущего пользователя Windows. Администратор
  и программа сотрудника должны запускаться под ОДНОЙ учётной записью.
  Для разных учётных записей нужен отдельный сервис с разграничением прав.
- В текущем прототипе сотрудник с теми же правами может добраться до
  сохранённых данных, поэтому администраторский режим НЕ является надёжной
  границей безопасности. Требуется выделенная SFTP-учётная запись с
  ограниченным доступом, не root.
- Файл пароля не хранится в открытом виде, а пароль WinSCP передаётся через
  stdin; до тестирования на Windows невозможно подтвердить отсутствие
  утечек во всех сторонних механизмах диагностики.
- Публикация нескольких файлов не атомарна как единая транзакция.
- В момент переименования целевой файл может кратковременно отсутствовать.
- Восстановление после потери соединения может потребовать вмешательства.

ЗАПРЕЩЕНО проверять на рабочем сайте без резервных копий и тестового каталога.

Зависимости: Python 3 (с Tkinter) + включённый WinSCP 6.7 Portable.
Тесты разработчика: python -m pytest tests

Для конечной сборки без Python: на Windows установить PyInstaller и выполнить
Собрать-на-Windows.bat; тестировать собранные exe отдельно.
