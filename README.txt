РКТМ — Расписание 5.0.0

Установите RKTM-Setup-5.0.0-x86.exe и откройте «РКТМ — Расписание».
Это одно приложение для публикации и настройки.

1. Вкладка «Настройки»: SFTP-сервер, порт, пользователь, пароль,
   отпечаток ключа SSH и папка публикации. Проверьте связь и сохраните.
   Можно выбрать папку на сервере через встроенный проводник.
2. Вкладка «Расписание»: ZIP, папка или HTML-файлы.
   Проверьте список, нажмите «Проверить файлы», затем «Опубликовать».
   Вложенные папки служат для поиска HTML; файлы публикуются без подпапок.
3. Во вкладке «История» хранятся локальные результаты новых публикаций.

Установка для текущего пользователя, пароль защищён Windows DPAPI.
Старые настройки APPDATA/RKTM-Rebuild/config.json сохраняются.
Во время операции нельзя менять вкладку или закрывать приложение.
Файлы с ошибкой остаются в списке для повторной отправки.

Один x86-установщик предназначен для Windows 7 SP1 и более новых x86/x64 систем.
Сборка и тесты выполняются на Windows Server 2022; отдельная проверка
на настоящей Windows 7 SP1 всё ещё необходима.
На Windows 7 могут потребоваться обновления Windows и Universal C Runtime.
У программы нет встроенного браузера. Интернет нужен для публикации по SFTP.
Без доверенной цифровой подписи Windows может предупреждать об издателе.
