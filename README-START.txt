РКТМ — проект автономной сборки Windows (v4.1)

ВАЖНО: Это исходники + автоматизированная сборка, а не уже испытанный установщик.
Чтобы получить готовый RKTM-Setup.exe, запустите GitHub Actions workflow Windows offline release
в репозитории с содержимым этого архива; скачайте результаты из Artifacts.
При сборке на Windows нужны Python и PyInstaller, но конечному пользователю они НЕ нужны.
WinSCP Portable уже включён в проект и офлайн-пакет. Во время установки ничего не скачивается.

ОГРАНИЧЕНИЕ БЕЗОПАСНОСТИ: текущая v4 использует DPAPI CurrentUser, то есть настройка и
загрузка должны выполняться из одного Windows-профиля; это НЕ надёжное разграничение ролей.
Не устанавливать как рабочую систему колледжа до отдельного сервисного аккаунта,
интеграционных SFTP и UI-тестов Windows.

Пароль root из переписки обязательно сменить. Для загрузки нужен ограниченный SFTP-аккаунт.
